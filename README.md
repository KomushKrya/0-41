# К.О.Н.Т.У.Р. / 0-41

Ранний прототип 3D-комнаты оператора на Godot 4.7 .NET.

## Требования

- Godot 4.7 .NET
- .NET 8 SDK

Главная сцена: `res://scenes/main.tscn`.

## Сборка

```powershell
dotnet build
```

Откройте проект в Godot .NET и запустите главную сцену для проверки прототипа.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W`, `A`, `S`, `D` | Перемещение игрока |
| `Space` | Подъём в прототипном контроллере полёта |
| `Ctrl` | Спуск в прототипном контроллере полёта |
| `E` | Взаимодействие с объектом под центральным лучом |
| `Esc` | Выход из сфокусированного объекта; вставание со стула; вне этих состояний переключение захвата мыши |

## Команды Отладки

| Клавиша | Действие |
| --- | --- |
| `F2` | Показать или скрыть GameSession (состояние прохождения), последние события EventBus (шины событий) и маркер центрального луча |
| `F3` | Показать или скрыть отладочную панель интерфейсов |
| `1` | Открыть предпросмотр SubViewport (вложенного viewport) ПК при включённом F3 |
| `2` | Открыть предпросмотр SubViewport карты при включённом F3 |
| `3` | Открыть предпросмотр SubViewport досье при включённом F3 |
| `4` | Открыть предпросмотр SubViewport блокнота при включённом F3 |
| `F4` | Показать или скрыть интерактивные области `Control` в активном SubViewport при включённом F3 |
| `F5` | Показать или скрыть дороги и здания карты при включённом F3 |
| `Esc` | Закрыть активный предпросмотр в режиме F3 |

## Сценарий Проверки

1. Запустите `main.tscn` и нажмите `F2`, чтобы увидеть начальное состояние `GameSession`.
2. Нажмите `F3`, затем `1`, и нажмите `START SHIFT` в предпросмотре ПК.
3. Нажмите `F2` ещё раз. Состояние смены станет `InProgress`, время начнёт увеличиваться, а EventBus покажет `ShiftStartRequested` и `ShiftStateChanged`.
4. Для взаимодействия с ПК в комнате сядьте на стул, наведите центральный луч на экран монитора и нажмите `E`. Корпус монитора подсветится, а целью взаимодействия останется экран.
5. Нажмите `Esc`, чтобы вернуться из ПК к виду со стула, затем ещё раз `Esc`, чтобы встать.

Маркер в центре экрана при F2 показывает логическое направление луча взаимодействия игрока.
