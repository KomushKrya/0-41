# Справочные материалы по интерфейсу

Макеты и заметки художника — то, по чему сверяется вёрстка. В игру ничего
отсюда не грузится, поэтому папка закрыта `.gdignore`: Godot её не
импортирует и в дереве ресурсов эти файлы не появляются.

| Файл | Что это |
|------|---------|
| `radio-screen/radio_screen_mockup.jpg` | макет экрана выбора по рации, 1920×1080 |
| `radio-screen/radio_screen_transition_example.ogv` | как задуман переход к этому экрану |
| `mission_image_briefs.txt` | тексты вызова и доклада по каждому заданию — по ним раскладывались кадры |

Готовые кадры лежат в `assets/textures/ui/illustrations/missions/`,
маски переходов — в `assets/video/transition_masks/`.

## Правила вёрстки экрана рации

Из заметок к поставке:

- макет 1920×1080, экран верстается в 1280×720 — всё делится на 1.5;
- шрифт `kontur_soviet_typewriter.otf`, цвет `#bfb8b6`;
- заголовок 36 pt жирный, межбуквенное расстояние +100;
- текст 22 pt жирный, подписи кнопок 22 pt обычный.

Кегли в теме `assets/themes/KonturUi.tres` заданы уже в координатах
1280×720, то есть в полтора раза меньше макетных.
