# Темы интерфейса

`KonturUi.tres` — общая тема экранов звонка (`PhoneCallAcceptanceUI`) и
рации (`RadioDecisionUI`). Подключена к корневому узлу обеих сцен, поэтому
любая кнопка, положенная внутрь, одевается автоматически.

Кнопки текстурные: каждому состоянию соответствует свой `StyleBoxTexture`.
Смена текстуры при наведении — работа самого `Button`, писать код не нужно.

| Слот темы                | Когда рисуется                        |
|--------------------------|---------------------------------------|
| `Button/styles/normal`   | кнопка доступна, курсор мимо          |
| `Button/styles/hover`    | курсор над кнопкой (активная текстура)|
| `Button/styles/pressed`  | кнопка зажата                         |
| `Button/styles/disabled` | вариант недоступен                    |
| `Button/styles/focus`    | кнопка выбрана с клавиатуры           |

Как одеть все кнопки сразу: открыть `KonturUi.tres` → Button → Styles →
в каждом слоте раскрыть StyleBoxTexture и положить PNG в поле `Texture`.
Текстуры кладём в `assets/textures/ui/buttons/`.

Как задать уникальную текстуру одной кнопке: выделить её в сцене →
Inspector → Theme Overrides → Styles → Normal/Hover. Override перебивает
тему только для этой кнопки, остальные продолжают брать общие текстуры.

`content_margin_*` — отступ текста от краёв текстуры. Если текст упирается
в рамку, увеличиваем его, а не размер кнопки.

Если у текстуры есть рамка, которую нельзя растягивать, задай в
StyleBoxTexture поля `Texture Margins` — это 9-slice, углы останутся целыми.
