# Маски переходов

Чёрно-белые видео (Ogg Theora, `.ogv`), управляющие тем, как экран
проявляется поверх кадра игры. Яркость кадра маски = прозрачность нового
экрана: чёрное оставляет прошлый экран (в размытии), белое открывает UI.

- `call/` — переходы экрана входящего вызова (`PhoneCallAcceptanceUI`);
- `radio/` — переходы экрана радиосвязи (`RadioDecisionUI`);
- `Экран-выбора-маска.ogv` — старая единственная маска рации, пока
  остаётся подключённой в `scenes/ui/radio/RadioDecisionUI.tscn`.

Файлы обязаны иметь расширение `.ogv` — без него Godot их не импортирует
и в дереве ресурсов они просто не появятся.

Маска проигрывается один раз (`loop = false`); её длительность и задаёт
длину перехода. Ограничение сверху — `TransitionTimeoutSeconds` в
`RadioDecisionUI` (по умолчанию 4 с): если видео не доиграет, переход
снимется принудительно, иначе невидимый блокировщик ввода запрёт игрока.
