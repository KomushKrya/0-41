# Рамки заголовка

Декоративные линейки, между которыми стоит название вызова.

| Файл | Размер | Где |
|------|--------|-----|
| `title_frame_top.png`    | 1033×38 | над заголовком |
| `title_frame_bottom.png` | 1038×14 | под заголовком |

Из макета в 1920×1080, в сцене ложатся в 689×25 и 692×9 — экран верстается
в координатах 1280×720. Ставятся как `TextureRect` со `stretch_mode`
«растянуть», без 9-slice: пропорции сохраняются, растягивать по частям
нечего.

Ширина у них разная на пять точек — так в исходнике. Если рамки должны
совпадать по краям, это правится в PSD, а не подгонкой в сцене.
