# Текстуры кнопок интерфейса

Сюда кладём текстуры кнопок экранов звонка и рации.

На каждую кнопку нужны минимум две текстуры:

| Состояние | Суффикс     | Когда видно                          |
|-----------|-------------|--------------------------------------|
| Обычное   | `_normal`   | кнопка доступна, курсор мимо         |
| Активное  | `_hover`    | курсор над кнопкой                   |
| Нажатое   | `_pressed`  | необязательно, по умолчанию = hover  |
| Недоступное | `_disabled` | необязательно, по умолчанию = normal |

Пример: `option_button_normal.png`, `option_button_hover.png`.

Общие для всех кнопок текстуры назначаются один раз в теме
`assets/themes/KonturUi.tres` (Button → Styles → Normal/Hover/...).
Кнопке с уникальной картинкой текстура задаётся прямо в сцене:
инспектор → Theme Overrides → Styles → Normal/Hover.

Текстуры растягиваются по размеру кнопки. Если у кнопки есть рамка,
которую нельзя растягивать, задай в StyleBoxTexture поля `Texture Margins`
(9-slice) — тогда углы останутся нетронутыми.
