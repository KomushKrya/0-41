# Кадры заданий

152 картинки по одной на экранный момент задания. Раскладка —
`day_<день>/<id миссии>/<вид>.jpg`, id папки совпадает с `id` в
`data/missions.json`, так что путь собирается из данных без таблицы
соответствий:

    res://assets/textures/ui/illustrations/missions/day_2/m_platform_wait/call.jpg

| Файл | Где показывается |
|------|------------------|
| `call.jpg` | экран входящего вызова (`PhoneCallAcceptanceUI`) |
| `radio_problem.jpg` | экран рации, доклад группы с места (`RadioDecisionUI`) |
| `radio_A_success.jpg` / `radio_A_fail.jpg` | итог операции после первого варианта |
| `radio_B_*`, `radio_C_*` | то же для второго и третьего варианта |
| `noradio_success.jpg` / `noradio_fail.jpg` | итог задания без рации |

Буква — это порядковый номер варианта на экране, а не его id: A — первый
вариант в `options` соответствующей записи `data/radio.json`, B — второй,
C — третий. Порядок в данных и есть порядок кнопок, поэтому индекс
переводится в букву напрямую (`'A' + index`). Заводить в файлах имена
вроде `radio_pass_by_success` не стали: художник нумерует варианты по
макету, id живут в данных, и связывать их лучше в одном месте — в коде.

Задания без рации (`missionEventId` пустой) имеют ровно три кадра: `call`
и пара `noradio_*`. Проверено по данным для всех 29 заданий: число букв
у каждого набора совпадает с числом вариантов в `data/radio.json`, пропусков
нет.

## Имена файлов

Из исходной поставки убран префикс с номерами дня и задания (`1_2_call.jpg`
→ `call.jpg`): день и задание уже записаны в пути, а второй номер задания
не сходился с порядком в данных и только путал. Заодно выправлен единственный
файл, названный `3_8_problem.jpg` вместо `radio_problem` — теперь и он
`radio_problem.jpg`.

## Раскладка по заданиям

Художник сдал картинки под нумерацией из «Миссии всех смен.docx». Дни там
совпали с `data/missions.json` полностью, но в третьем дне задания 2 и 3
переставлены: `3_2` в документе — `m_dense_flock`, `3_3` — `m_dogs_at_grate`,
а на кадрах наоборот. Разложено по кадрам: `3_3_radio_problem` — двор
автобазы с особями на задних лапах, это `m_dense_flock`; `3_2_call` —
дворник у телефонной будки ночью, это `m_dogs_at_grate`. Число вариантов
по рации это подтверждает.

Тексты вызова и доклада, по которым сверялись кадры, лежат в
`docs/ui-references/mission_image_briefs.txt`.

## Размеры

Все кадры из макета 1920×1080. На экране рации картинка идёт фоном во весь
экран (`stretch_mode = 6`, Keep Aspect Covered), на экране звонка —
в рамке `IllustrationPanel` с обрезкой маской из `../../illustration_masks/`.
