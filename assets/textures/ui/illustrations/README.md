# Иллюстрации звонков и радио

Картинки, которые показываются на экранах:

- на экране звонка — иллюстрация вызова в рамке `IllustrationPanel`
  (`PhoneCallAcceptanceUI`);
- на экране рации — кадр с камеры группы и последствие операции, фоном
  во весь экран (`RadioDecisionUI`).

Сами кадры разложены по заданиям в `missions/` — там же README про
раскладку и имена. В этой папке лежит только то, что не привязано
к конкретному заданию.

Форма под картинку на экране звонка растягивается с сохранением пропорций
(`stretch_mode = 5`, Keep Aspect Centered), так что точный размер исходника
не важен — важны пропорции, близкие к 1:1.

Маски, обрезающие эти картинки, лежат рядом в `../illustration_masks/`.
