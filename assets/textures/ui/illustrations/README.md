# Иллюстрации звонков и радио

Картинки, которые показываются в рамке `IllustrationPanel`:

- на экране звонка — иллюстрация вызова (`PhoneCallAcceptanceUI`);
- на экране рации — изображение с камеры группы и последствие операции
  (`RadioDecisionUI`).

Формы под них в сцене растягиваются с сохранением пропорций
(`stretch_mode = 5`, Keep Aspect Centered), так что точный размер исходника
не важен — важны пропорции, близкие к 1:1.

Маски, обрезающие эти картинки, лежат рядом в `../illustration_masks/`.
