# Разделённые модели кабинета

Исходный `assets/models/environment/import/кабинет.glb` разделён на 45 самостоятельных GLB-файлов и удалён после проверки результата.

## Каталоги

- `architecture` — 13 элементов помещения, дверей, окна и радиатора;
- `furniture` — 7 предметов и частей мебели;
- `interactive` — 11 мешей интерактивных устройств;
- `lighting` — 1 модель настольной лампы;
- `decor` — 13 декоративных объектов.

Исходные текстуры размещены рядом с соответствующими категориями моделей в каталогах `architecture/textures`, `furniture/textures`, `interactive/textures` и `lighting/textures`. Текстуры, общие для нескольких категорий, находятся в `shared_textures`.

Каждый `.glb` содержит один исходный меш с его материалами. Корень модели перенесён в локальный ноль для удобства повторного использования, но исходный базис, масштаб и габариты сохранены.

Файл `manifest.json` содержит для каждого объекта:

- английское имя и категорию;
- путь к отдельному GLB;
- исходный путь узла;
- точные габариты в метрах;
- исходный `Transform3D` относительно кабинета;
- локальный AABB меша, число поверхностей и размер файла.

Для восстановления исходной расстановки нужно применить к корню объекта `original_transform` из манифеста. Столбцы `Basis` записаны как `basis_columns`, позиция — как `origin`.

Все 45 файлов повторно прочитаны через `GLTFDocument`. Их размеры совпадают с исходными с допуском 0,001 м.

Повторный экспорт выполняет `tools/editor/split_office_glb.gd`, проверку — `tools/editor/validate_split_office_glb.gd`.
