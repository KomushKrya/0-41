# Ролики между сменами

Проигрыватель ищет здесь файл с именем, равным id катсцены:

    cutscene_intro.ogv
    cutscene_before_shift_2.ogv
    cutscene_before_shift_3.ogv
    cutscene_before_shift_4.ogv
    cutscene_part_1_end.ogv

**Формат — только `.ogv` (Ogg Theora).** Godot из коробки не умеет ни mp4, ни webm:
кодеки лицензируются отдельно, и в сборку они не входят. Конвертировать можно чем
угодно, например `ffmpeg -i вход.mp4 -q:v 7 -q:a 5 выход.ogv`.

**Файла может не быть — это нормально.** Тогда проигрыватель показывает текстовую
версию катсцены из `content/raw/cutscenes/`, покусочно по нажатию пробела. Так
играть можно уже сейчас, а видео подкладывается позже, без единой правки в коде.

Если ролик добавили, а он не проигрывается — проверьте, что имя файла совпадает
с id записи в тексте, а не с названием файла `.md`.
