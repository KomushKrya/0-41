# Это копия. Источник истины — `data/` в корне проекта

Папка нужна была, пока ядро жило отдельным репозиторием и запускалось без игры.
После интеграции контент один и лежит в корне: `data/`. Здесь — его дубликат.

## Чем это опасно

Дубликат уже один раз разошёлся с оригиналом, и обнаружилось это не сразу.
Харнесс искал «ближайшую папку с `config.json`», а эта копия лежит ближе к своему
бинарнику, чем корневая `data/`. В итоге прогон баланса шёл по одному контенту,
а игра — по другому. Заметили только тогда, когда в `data/employees.json` появился
раздел `generator`, которого здесь не было, и самопроверка сказала, что фабрика
кандидатов выключена — хотя в игре она работала.

## Что сделано, чтобы не повторилось

- Харнесс сначала ищет корень игры (папку с `project.godot`) и берёт `data/` оттуда.
  Эта копия используется, только если корня нет — то есть ядро выкачали отдельно.
- Прогон печатает путь к контенту в шапке: `источник: ...`. Если там не `data/` —
  вы смотрите не на те числа.
- `tools/lint-core.py` сравнивает файлы и ругается на расхождение.

## Что с этим делать

Лучше всего — **удалить эту папку целиком**. Ничего не сломается: харнесс найдёт
`data/`, а автономный прогон без игры можно запустить с явным путём:

```
dotnet run --project src/Kontur.Harness -- --content ../data
```

Пока папка жива, держите её синхронной: `copy /Y ..\..\data\*.json .` из этой папки.
