# _system

Служебные материалы для авторов, а не игровой контент. Конвертер (`content/engine/converter`)
должен пропускать всё, что лежит под `_system/` — сюда никогда не должны попадать `.md`
с реальными `id`, которые ожидает игра.

- `Templates/` — заготовки для Templater (по одной на каждый тип контента: incident, radio,
  creature, shift_note, report, story). Использовать при создании нового файла в
  соответствующей папке `content/raw/<тип>/`.
- `Syntax/` — описание общей схемы фронтматтера и кастомных тегов (ссылки между id,
  раскрытие абзацев по свойствам, варианты радио-решений). Черновик, дополнять по мере
  того как конвертер будет реально их парсить.

Папки под конкретные типы контента (`incidents/`, `radio/`, `creatures/`, `shift_notes/`,
`reports/`, `story/`) создаются рядом с `_system/`, когда начнётся написание самих текстов —
их здесь пока нет.
